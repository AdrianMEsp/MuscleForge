
# Muscle Forge

Este es un proyecto personal que me motivo a desarrollarme en kotlin-android, se trata de una app para armar ejercicios con rutinas, la posibilidad de  crear, modificar y eliminar estos dos elementos , la navegacion entre fragmentos y como relacionarlos, modificarlos y editarlos para que muestren lo necesario, con una base de datos en memoria Room,  Utilizando clases Dao, Repository, Adapter, ViewModel y Fragment para lograr encapsulamiento y organizar el codigo
